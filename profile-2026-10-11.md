# Runtime profile of every benchmark chip, to the end of the feedline refinement

Written for the user, 2026-10-11. Branch `phase-4-routing-stages`, HEAD
`c3c3e53` plus the uncommitted changes listed under *Changes in the tree*.

## Setup

- The capacity rule, the profile cuts and the bottleneck report are now on by
  default: `SCPD_CAPACITY_RULE`, `SCPD_CAPACITY_FAST` (1) and
  `SCPD_BOTTLENECKS`. The runs set none of the three.
- Each chip's `benchmarks/<chip>/config.toml` with `stop_after = "refined"`, so
  the Final stage runs to the end of the feedline refinement.
  `repair_trials = 0` as in the benchmark configs.
- `SCPD_SEARCH_PICTURES=0`, `-v 1`. One chip at a time on the Mac (Apple
  silicon, macOS 15.7); nothing else ran beside the chips, because the chain
  search has a wall-clock budget.
- Every log line carries the wall-clock seconds since the start of the run.
  `sample` recorded the call tree of the main thread every 1 ms. The extension
  was linked without `-Wl,-x -Wl,-S` (the same `-O3` LTO build, with symbols).
- Scripts and data, in `artifacts/logs/profile/` (ignored by git):
  `run.sh <out dir> [chip …]` runs the chips; `report.py <out dir> <chip>`
  prints the phases, the results and the hotspots; `all/` holds the logs, call
  trees, reports (`<chip>.report.md`) and run directories; `opt/` holds the runs
  after the two speed-ups below.

## What can be gained without parallel work

Ordered by what each item is worth on the large chips. Each item gives the same
result as the code today unless it says otherwise.

### Done: two speed-ups with the same result (in the tree, uncommitted)

1. **`priceRoom` works inside the box only.** It filled two 32-bit fields of the
   whole grid and divided once per grid cell at every search, although every
   cell outside the box keeps the full price. The fields are now sized once and
   set inside the box; the last loop runs over the box.
2. **`rebuildPacked` reads the corridor one 64-bit word at a time.**

`06-final.fb` is byte for byte the same on 9q, 17q, 21q, 33q and 45q
(`artifacts/logs/profile/opt/`). Whole run: 9q 15 → 15 s, 17q 47 → 47 s, 21q 82
→ 75 s, 33q 98 → 93 s, 45q 252 → 238 s (refinement 77 → 67 s, feedline
refinement 53 → 47 s). 57q and 69q were not run again.

### Open, with the same result

3. **`freeStripAlong` once per straight, not once per pair** (57q 12.5 %, 17q
   12.9 %, 69q 5.9 %). `insertMeander` asks for the free strip of every pair of
   cells on the straights, and each call pushes a Bresenham line out one offset
   at a time until a cell is blocked: O(width × length) per pair. On an
   axis-parallel straight, the strip of a pair is the minimum over its cells of
   how far each cell's column is free on each side. One pass per straight gives
   that depth for every cell, and a range-minimum query gives each pair's strip
   in O(1). Diagonal straights round the offsets: those can keep the current
   walk or need a proof that the column test matches it.
4. **`rebuildPacked` and `corridorOfEdge` only inside the box.** Both still walk
   the whole grid at every search (69q: 9.2 % and 4.5 %; 9 M cells on 33q).
   Outside the box the corridor is closed and `packed_` is `0x80 | static_`,
   which does not change between searches, so only the union of the old and the
   new box has to be rewritten. `corridorOfEdge` can close the rows outside its
   box word by word and set cells one by one inside the box only.
5. **`priceRoom` and `buildCorridor` still cost 10-23 % on the chips with a band
   of 798 cells** (9q, 17q, 21q, 45q, 57q), because a band that wide makes the
   box most of the chip. Options:
   - Run the chamfer passes inside the bounding box of the cells the walk
     reached, grown by one cell. Every cell outside it is a wall in both fields,
     and the passes never carry a value through a wall, so the result is the
     same.
   - Keep the corridor of a wire whose way, reach and fences did not change
     since its last search (the later refinement rounds keep many ways).
   - Merge `scene_.blocked` and `bodies_` into one byte mask per pass, so that
     the walk tests one byte instead of two bit grids per neighbour.
6. **`ChainBuilder::flood` with dense fields** (capacity stage; 69q about 33 s
   of its 60 s). `local`, `visited_` and the targets are `std::unordered_set`s
   of cell indices, with one hash lookup per neighbour. A field of the grid's
   size with a pass counter, as `buildCorridor` uses with `seen_`, gives the
   same chambers.
7. **The A\* core** (35-45 %). Smaller gains: `hypot` (1-2 % with its stub) can
   be `sqrt` where the argument cannot overflow; `CrossingConstraints::allowed`
   (2-4 %) is called per expansion and can be read from a per-search table.

### Not worth it

- `getenv`: `capacityRule()` and `bottleneckReport()` read the environment at
  every call (`__findenv_locked` 0.2 % on 9q). Too small to matter.
- The capacity check: at most 23 s on 69q (20 % of the insertion).

Two groups:

- **Far too short** (4q 9, 17q 26, 17q 44, and 17q 1): the way has too few
  straight cells for a loop. They need a longer way first, not a meander.
- **Within 3-5 % of the target** (21q 37, 33q 80, 69q 3, 69q 164): 15-25 cells
  are missing. The loops the search can build add more than the tolerance
  allows, or replace a stretch that is longer than the loop. A smaller loop, or
  a jog that lengthens a straight by a few cells, would close them.

## Changes in the tree

- `src/pipeline/FinalRouter.cpp`: the three switches default to on; `priceRoom`
  works inside the box only.
- `src/routing/DubinsRouter.cpp`: `rebuildPacked` reads words.
- `test/pipeline/test_final_router.cpp`: new
  `FinalRouter.TheCapacityRuleAndTheBottleneckReportAreOnByDefault`;
  `TheStepCheckSaysForEveryFeedlineEdgeWhetherTheGraphCarries` sets
  `SCPD_CAPACITY_RULE=0`, because it compares against a run without the rule.
- `test/python/unit/test_capacityview.py`: the test without a page sets
  `SCPD_BOTTLENECKS=0`.
- `python/mqt/scpd/cli.py`, `capacityview.py`: docstrings.
- `CHANGELOG.md`, `UPGRADING.md`: the new defaults.
- The installed extension in `.venv` is the build with symbols; the stripped
  build is saved as `artifacts/logs/profile/pyscpd-stripped.abi3.so`.
  `uv sync --inexact --no-dev --no-build-isolation-package mqt-scpd --reinstall-package mqt-scpd`
  installs a normal build again.
